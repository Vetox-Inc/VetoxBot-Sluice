# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, keep discussion on the work, and harass no one — in issues, pull requests
and anywhere else the project is discussed.

Report unacceptable behavior to the maintainers privately: open an issue that asks for a private contact, without
details, and a maintainer will reach out. Reports are handled confidentially, and maintainers may remove comments,
commits or contributors that break this code.
